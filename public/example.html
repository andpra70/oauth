OAuth End-to-End Example

Questa pagina avvia il flow OIDC completo, gestisce il callback, scambia il code con i token, legge /me e permette di chiudere la sessione. Nella schermata server-side di login puoi usare credenziali locali, Accedi con Google oppure Registrati con Google.

Console completa: /app

Avvio rapido

Pronto. Premi "Avvia login OAuth" per iniziare.

Tokens

Nessun token disponibile.

UserInfo

Nessun profilo caricato.

Cosa copre

  1. Genera state, code_verifier e code_challenge.
  2. Chiama /auth con Authorization Code + PKCE.
  3. Passa dalla pagina di login server-side.
  4. Completa il callback su /example/callback.
  5. Esegue POST /token e poi GET /me.

Login disponibili

  1. Login locale con username/password e TOTP se abilitato.
  2. Accedi con Google per un account Google già noto.
  3. Registrati con Google per creare il record utente in db.json.

Note

Il pulsante Google compare solo se il server è configurato con GOOGLE_CLIENT_ID e GOOGLE_CLIENT_SECRET.
